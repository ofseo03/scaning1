scan2doc

사진·스크린샷·PDF를 OCR로 읽어 Word(.docx)와 한글(.hwpx) 문서로 바꿔 주는 명령줄 도구입니다. 글자만 뽑는 데서 그치지 않고 제목·문단·목록 구조까지 되살립니다.

이 페이지는 안내문입니다. scan2doc은 내 컴퓨터에서 도는 프로그램입니다. OCR이 tesseract 실행 파일을 직접 부르고 변환에 시간이 걸리기 때문에, 여기서 파일을 올려 변환할 수는 없습니다. 아래 방법으로 설치해 쓰세요.

설치

# 1) OCR 엔진 (한국어 데이터 포함)
sudo apt install tesseract-ocr tesseract-ocr-kor   # Ubuntu/Debian
brew install tesseract tesseract-lang              # macOS

# 2) scan2doc
git clone https://github.com/ofseo03/scaning1.git
cd scaning1
pip install -e ".[preprocess]"

scan2doc doctor   # 설치 상태 점검

쓰기

scan2doc 계약서.jpg              # → 계약서.docx + 계약서.hwpx
scan2doc 사진/ -o 결과/ --merge  # 폴더 전체를 문서 하나로
scan2doc 보고서.pdf -f docx --pages 1-5
scan2doc 영수증.jpg --binarize   # 그림자 진 사진
scan2doc serve                   # 로컬 웹 UI (localhost:8000)
scan2doc gui                     # 창으로 쓰기

지원하는 형식

입력JPG · PNG · BMP · GIF · TIFF(여러 장) · WEBP · PDF · 폴더
출력Word .docx · 한글 .hwpx / .hwpml · .txt · .md
언어한국어 + 영어 기본, Tesseract가 지원하는 모든 언어

한글 문서에 대해

기본 출력은 .hwpx입니다. 한컴이 공개한 OWPML(KS X 6101) 국가표준이라 규격대로 만들 수 있고 한/글 2014 이상에서 그대로 열립니다. .hwp가 필요하면 한/글에서 연 뒤 다른 이름으로 저장을 쓰세요. 한/글 2007~2010이라면 --hwp-format hwpml을 쓰면 됩니다.
