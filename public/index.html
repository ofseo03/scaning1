      이 화면은 브라우저 안에서 도는 판입니다. 쪽수가 많거나 자주 쓰신다면 컴퓨터에 설치해서 쓰는 편이 훨씬 빠릅니다. 폴더 통째로 변환, 기울기 자동 보정, 노이즈 제거 같은 기능도 설치판에만 있습니다. 

      sudo apt install tesseract-ocr tesseract-ocr-kor   # Ubuntu/Debian
brew install tesseract tesseract-lang              # macOS

git clone https://github.com/ofseo03/scaning1.git
cd scaning1 && pip install -e ".[preprocess]"

scan2doc 계약서.jpg              # → 계약서.docx + 계약서.hwpx
scan2doc 사진/ -o 결과/ --merge  # 폴더 전체를 문서 하나로
scan2doc serve                   # 내 컴퓨터에서 이 화면 띄우기

      .hwp 가 필요하면 한/글에서 .hwpx를 연 뒤 다른 이름으로 저장을 쓰세요. .hwpx는 한컴이 공개한 OWPML(KS X 6101) 국가표준이라 한/글 2014 이상에서 그대로 열립니다.
